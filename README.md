# Nawa Cafe Website

Production website and staff dashboard for Nawa Cafe.

## Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase
- Vercel

## Local Development

```sh
npm install
npm run dev
```

The local development server runs on port `8080`.

## Production

Production is deployed on Vercel and served at:

```txt
https://nawacafe.com
```
